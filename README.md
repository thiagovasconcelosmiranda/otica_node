# Ótica

> Projeto desenvolvido para facilitar na busca de seu óculos favoritos.

## 🚀 Tecnologias

As seguintes ferramentas e tecnologias foram usadas na construção do projeto:
* [Node.js](https://nodejs.org/) (Versão 18.x ou superior)
* [Express](https://expressjs.com) (Ou outro framework utilizado)

---

## 📋 Pré-requisitos

Antes de começar, você vai precisar ter instalado em sua máquina:
* [Git](https://git-scm.com)
* [Node.js](https://nodejs.org/) (recomenda-se a versão LTS)
* Um gerenciador de pacotes como **npm**.

---

## ⚙️ Como Instalar e Rodar o Projeto

Siga os passos abaixo para executar o projeto em seu ambiente local:

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/otica_node/
   ```

2. **Entre na pasta do projeto:**
   ```bash
   cd otica_node
   ```

3. **Instale as dependências:**
   ```bash
   npm install
   ```
   *(Ou `yarn install`, caso utilize o Yarn)*

4. **Configure as variáveis de ambiente:**
   * Renomeie o arquivo `.env` (se houver) e preencha com as suas configurações locais.

5. **Execute o projeto em modo de desenvolvimento:**
   ```bash
   npm run dev
   ```
   *(O servidor iniciará normalmente na porta definida, ex: `http://localhost:3000`)*
